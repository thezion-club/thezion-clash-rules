## Architectural Rules for LLMs

1. **Rule-set Source of Truth**:
   - `.txt` files are YAML payloads acting as the primary source of truth.
   - `.mrs` files are compiled binary formats generated by `mihomo convert-ruleset`. Never edit `.mrs` files directly.
2. **Managed Sections in `thezion-direct.conf`**:
   - The `# Apple@cn` block is generated by `update_apple_cn` in `update.sh`.
   - The `# ASN Extract` block is generated by `update_asn_extract` calling `extract_asn.py`.
   - Hand edits between these headers and the next `# ` section header will be overwritten upon script execution.
3. **Caching and Exclusion System**:
   - Cache artifacts reside in `tmp/` (gitignored).
   - `exclude.conf` holds exclusion patterns for `direct.txt` and `proxy.txt`. Changes to `exclude.conf` trigger automated regeneration of affected rule-sets.
4. **Git Operations**:
   - Commits should be made only when explicitly requested by the user.
   - The backup branch `backup-main` preserves the pre-rebase history.
